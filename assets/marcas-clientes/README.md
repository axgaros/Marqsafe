# MarqSafe — logos de marcas/clientes

Assets proporcionados por el cliente para la sección de confianza / prueba social de la Home.

## Propósito

Estos logos se usarán en el carrusel de **marcas con las que MarqSafe ha trabajado**, sujeto a confirmación de autorización para exhibición pública antes de producción.

## Normalización aprobada

- relación de aspecto: 1:1
- tamaño de trabajo: 800 × 800 px
- formato web objetivo: WebP
- fondo neutral claro
- logo centrado con `contain`
- no redibujar ni alterar el diseño de las marcas con IA
- conservar color original salvo decisión posterior explícita

## Carrusel aprobado para móvil

- scroll horizontal nativo
- `overflow-x: auto`
- `scroll-snap-type: x mandatory`
- tarjeta central protagonista
- tarjetas laterales parcialmente visibles
- laterales con menor opacidad y blur muy leve
- sin autoplay
- `overscroll-behavior-x: contain`
- controles prev/next opcionales con target mínimo de 44 × 44 CSS px
- navegación accesible por teclado
- motion reducido cuando `prefers-reduced-motion` esté activo

En desktop se pueden mostrar varias marcas simultáneamente dentro de la misma banda para aprovechar el ancho disponible.
